Conventions

Access levels

  • Public No token needed.
  • Optional auth Works without a token. With one, the response is personalised (for example is_liked).
  • Login A valid bearer token is required. "Owner or admin" endpoints also check that you created the record or have is_admin = true.
  • Admin The token's user must have is_admin = true, otherwise 403.

Pagination

List endpoints take page (default 1) and limit (default 10, max 100) and return { total, page, limit, <items> }. The items key differs per module: events, stories, articles, listings, profiles or notifications.

Deletes

Events, stories, jobs, marketplace, transit and matrimony are soft-deleted (is_active = false). News, timeline entries, comments and gallery photos are hard-deleted. A successful delete returns 204 No Content with an empty body.

File uploads

Uploads use multipart/form-data with a field named file (or files for multi-upload). Accepted types are JPEG, PNG and WebP. The limit is 5 MB unless an endpoint says otherwise.
